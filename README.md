# Portfolio — nivokai

Portfolio personnel construit avec React, Vite et les composants animés de [React Bits](https://reactbits.dev).

## Lancer en local

```bash
npm install
npm run dev
```

## Modifier le contenu

Tous les textes, projets, technologies et chiffres sont dans [`src/data.js`](src/data.js).
Les captures d'écran des projets sont dans `public/shots/`.

## Mise en ligne

Chaque `git push` sur `main` construit le site et le publie sur GitHub Pages
(voir `.github/workflows/deploy.yml`).
